# Monitoramento-de-Fluxo-de-Carros-IFSULDEMINAS-UNICAMP
Este projeto surge da necessidade de melhorar a segurança patrimonial e a gestão de infraestrutura dentro do campus.
Atualmente, a transição entre o acesso restrito (dia) e o acesso livre (noite) dificulta a detecção de movimentações suspeitas em horários críticos, como a madrugada
